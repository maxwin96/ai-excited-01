The Whale Learned to Fly — a program that draws a 1024×1024 image from scratch, pixel by pixel, with only the Python 3 standard library. A giant blue whale breaches out of a curling wave and soars diagonally across a burning sunset sky above a sleeping city, spray bursting from its blowhole, a tiny astronaut riding its back waving a flag — and a short message for the judge up top. Fully deterministic: two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, 32,889 bytes).
